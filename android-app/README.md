# 一起看 Android 测试版

当前版本为 **0.3.10**（versionCode 15），配套 Windows **0.6.10**：包含手机版布局适配，以及用户选定的“陪伴”图标；安卓使用原生自适应矢量图标，另提供 Android 13 起的主题单色资源。两个安装包、服务器更新和验收步骤见 [本批完整更新步骤](../APP_ICONS_2026-10-25.md)。无需先安装 0.3.8 / 0.3.9。

0.3.8 的手机选片界面采用紧凑搜索栏、文字分类、双列封面和底部导航；首次选片时隐藏重复的原生标题栏，已有房间换片时仍保留返回和更多。完整效果需要更新服务器和安卓安装包；手机浏览器只需刷新新版网页。详见 [手机版界面更新](../MOBILE_CATALOG_UI_2026-10-25.md)。代码推送不会自动部署服务器，安装包本身也不会更新服务器页面。

0.3.7 的来源清理、封面读取修复继续保留，配套 Windows **0.6.8**。选好影片直接进入房间，首次使用只做简短确认；加入邀请使用独立小面板，离开房间回到选片。房间只常驻换片、邀请和全屏，播放方式、只看聊天、重连和离开房间放进顶部“更多”。此前流程说明见 [选片直达与房间按钮精简](../ROOM_CONTROLS_2026-10-23.md)。

0.3.4 的返回修复继续保留：搜索与播放分开保存，返回上一步不再重新开始找片；顶部返回按钮与安卓系统返回键使用同一逻辑。历史说明见 [返回修复](../NAVIGATION_FIX_2026-10-22.md)。

0.3.2 修复输入房间号后另开房、兼容房间同步路径和部分邀请格式，并支持确认看剧 AI 当前集数、复制纯房间号。历史记录见 [进房与同步修复说明](../ROOM_JOIN_SYNC_2026-10-21.md)。

0.3.1 修复严格网页安全策略下无法接管播放器的问题，并增加看剧 AI 窄屏布局与检测失败提示。这些改动已包含在 0.3.2 中，历史说明见 [0.3.1 修复说明](../ANDROID_SYNC_2026-10-20.md)。

0.2 测试版加入 Media3 内置播放器：能直接播放的来源在手机本地加载，暂不兼容的页面继续网页播放。视频、聊天和通话可以同屏使用，不需要拖书签或安装浏览器插件。详细试播步骤和限制见 [内置播放器说明](NATIVE_PLAYER.md)。

0.3.0 加入软件内找片、选集建房、邀请读取片源和房主换片跟随，并合入麦克风修复。收到新版房间的邀请后，不用再填视频链接。具体范围与验证边界见 [0.3.0 说明](../ANDROID_FLOW_2026-10-20.md)。

## 当前功能

- 先在软件内搜索、选集再建房；朋友只需填昵称和邀请链接
- 接入公开片源标识，换片时先确认集数再同步；不把媒体令牌放进邀请
- 粘贴视频播放页，或从其他应用通过“分享”发送网页链接
- 在本机识别网页媒体候选，使用内置播放器或保留网页同步助手
- 内置播放、暂停、拖动进度和倍速接入房间协议
- 竖屏上下分区、横屏左右分区，也可以全屏视频或只看房间
- 视频与通话音量分开调整；只影响自己的设备
- 房间页继续使用现有聊天、音量与 WebRTC 语音功能
- 支持 HTML5 视频全屏和横屏
- 仅接受公开 HTTPS 入口，过滤本机和常见私有 IP 地址；不作为网络隔离沙箱使用
- 视频网页不获得任何 Android JavaScript 原生桥接接口
- 麦克风权限只会授予 `watchtogethernow.cloud` 房间页

## 获取测试 APK

新版 APP 需要网站部署 `/api/watch-rooms`、`/mobile-room/<房间号>` 和对应脚本。仅安装 APK、不更新网站，无法完成新版选片邀请流程。

推送到 `main` 后，GitHub Actions 的 `android-apk` 任务会自动构建：

1. 打开仓库的 **Actions**。
2. 进入最新的 **android-apk** 任务。
3. 在页面底部下载 `together-watch-android-debug`。
4. 解压后得到 `app-debug.apk`，发送到安卓手机安装。

Actions 测试包使用临时调试签名，可能无法覆盖本地签名包。遇到冲突先核对来源，不要直接卸载丢失登录状态和房主凭据。正式发布前需固定签名密钥。

## 本地构建

需要 JDK 17、Android SDK 36 和 Gradle 8.13：

```bash
gradle -p android-app :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

APK 输出路径：

```text
android-app/app/build/outputs/apk/debug/app-debug.apk
```

## 测试步骤

1. 两部安卓手机安装同一版 APP，使用不同昵称。
2. 第一部点“选择开放短片试播”，选 Sintel；房间号留空并开始。
3. 点“邀请朋友”，另一部只粘贴邀请，视频链接留空；应自动打开同一片源并等待房间进度。
4. 两边就绪后测试暂停、播放、拖到 30 秒和改倍速，观察另一边是否跟随。
5. 在下方聊天发送消息，双方点“加入语音”并授权麦克风，建议戴耳机。
6. 一部退到后台再回来，检查它能否追上仍在播放的另一部。

## 已知限制

- 内置播放支持设备能够解码的 MP4/WebM、HLS/DASH；不保证任意网页、DRM、强制官方 APP、禁止 WebView 或特殊跨域播放器可用。
- 新房间使用打包的网页播放器适配器与房间版本协议；旧兼容房间仍使用网站的书签助手，双方需手动选同一影片。
- 若服务端未配置 TURN，严格 NAT、校园网或公司网下语音可能无法连接；安装 APP 本身不会解决这一点。
- 识别出的媒体链接只在当前手机会话内使用，不发给房间或其他成员。登录 Cookie 和 Authorization 不会从网页复制到内置播放器；每位用户必须自行登录并拥有观看权限。
- 搜索与选集依赖已适配目录；看剧 AI 本机统一搜索暂限 Windows 0.6.0，安卓可在原站选集后确认播放页。没有规则导入、离线下载或后台播放；这不是完整的 Kazumi 替代品。
- 公开分发或商用前仍需完成 APP 备案、隐私合规、正式签名、图标和应用商店材料。
