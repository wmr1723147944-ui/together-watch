# Together Watch 观影伴侣

这是一个 Manifest V3 浏览器扩展，用来在视频网站官方页面中同步 HTML5 播放器，并显示房间悬浮聊天室。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `browser-extension` 文件夹。

## 连接房间

1. 在 Together Watch 房间页粘贴官方视频网页地址。
2. 点击“使用这个链接”，确认来源后再点击“打开视频并在播放页聊天”；房间不会自动跳转。
3. 官方页面打开后会自动识别并连接房间，右侧出现聊天室、扩展角标出现“✓”即连接成功。

房间地址、房间号和昵称会自动带入扩展，不需要打开扩展或复制配置。自动识别失败时，再点击扩展图标检查状态，或展开“手动连接”填写信息。

每位成员仍需在官方网站使用自己的账号。会员影片能否完整播放由原网站判断，本扩展不会共享账号、Cookie、会员权限或媒体地址。

扩展弹窗中的“当前视频音量”和房间页中的“视频声音”都可以调整本机视频，不会影响房间里的其他成员。iPhone/iPad 不支持此桌面浏览器扩展，视频音量需要使用机身音量键。

扩展不读取 Cookie、账号密码或媒体地址，只读取播放器的当前时间、播放状态和倍速，并收发当前房间的聊天消息。
扩展只请求连接 `https://watchtogethernow.cloud` 所需的网络权限，不接受网页传入的其他服务器地址。
