# Together Watch 观影伴侣

这是一个 Manifest V3 浏览器扩展，用来在视频网站官方页面中同步 HTML5 播放器。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `browser-extension` 文件夹。

## 连接房间

1. 在 Together Watch 房间页点击“复制伴侣配置”。
2. 打开扩展弹窗，粘贴配置并点击“读取配置”。
3. 点击“保存并连接”，刷新官方视频页面。
4. 角标出现“✓”代表已连接。

扩展不读取 Cookie、账号密码或媒体地址，只读取播放器的当前时间、播放状态和倍速。
保存服务器时，浏览器只会请求访问该服务器所需的网络权限，不会一次申请所有网站的后台访问权限。
